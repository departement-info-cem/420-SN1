:::warning Rappel : indentez toujours avec la touche TAB ⌨️
- **`TAB`** pour indenter, **`Maj + TAB`** pour retirer une indentation.
- **N'utilisez jamais la barre d'espace** pour indenter.
- Toutes les lignes d'un même bloc doivent avoir **exactement la même indentation**.
- Sinon : `IndentationError`.
:::
