    <TabItem value="notebook-jupyter" label="📓 Notebook Jupyter">

        :::note Pourquoi cette recette n'est plus utilisée dans le cours?
        Dans le cours, tout le code est écrit dans des **fichiers Python** (`.py`) exécutés dans PyCharm. C'est aussi le format attendu pour les exercices, les TP et les examens.

        Les *notebooks* restent toutefois un outil incontournable en sciences : vous les croiserez sûrement dans vos cours de sciences, à l'université ou en stage de recherche (par exemple dans [Google Colab](https://colab.research.google.com)).
        :::

        ---

        Les ***notebooks Jupyter*** sont parfaits pour combiner texte, code et résultats dans un seul fichier interactif.
        Ils contiennent à la fois, de façon intermêlée :

        - des blocs de texte (en format *markdown* ou *html*)
        - des blocs de code Python qui peuvent être exécutés
        - des résultats d'exécution
        - des graphiques
        - des images

        Ils sont largement utilisés en sciences pour la recherche, l'exploration de données et l'enseignement.

        ---

        ## Créer un notebook

        Pour créer un nouveau notebook :

        1. [Créer un projet PyCharm](/recettes/autres-recettes?onglet=creer-projet) (ou en ouvrir un existant).
        2. Dans l'arborescence des fichiers du projet à gauche, cliquer-droit sur le dossier où on veut créer le notebook.
        3. Choisir **New > Jupyter Notebook**.
        4. Donner un nom au notebook (par exemple `mon_premier_notebook`) et appuyer sur ⏎.
        5. Un fichier avec l'extension `.ipynb` est créé dans l'arborescence des fichiers (par exemple `mon_premier_notebook.ipynb`)
        et s'ouvre dans un nouvel onglet.
        6. Le notebook contient une première cellule vide. Pour en ajouter d'autres, il suffira de cliquer sur le bouton ＋ dans
        la barre d'outils en haut.

        ---

        ### Écrire du texte

        1. Cliquer sur une cellule existante, ou en ajouter une nouvelle avec le bouton **＋**.
        2. Dans la barre d'outils du notebook, changer le type de cellule de **Code** à **Markdown**.
        3. Taper le texte en utilisant la syntaxe *Markdown* (voir exemple ci-dessous).
        4. Appuyer sur `Shift` ⏎ pour afficher le rendu formaté.

        #### Exemple de Markdown :

        ````markdown
        # Titre principal

        Voici du texte en **gras**, *italique* et un [lien](https://jupyter.org).

        - Une liste
        - à puces

        1. Une liste
        2. numérotée

        Voici un bloc de code non exécutable :

        ```python
        def salut():
            print("Bonjour!")
        ```
        ````

        #### Résultat affiché :

        :::tip .

        # Titre principal

        Voici du texte en **gras**, *italique* et un [lien](https://jupyter.org).

        - Une liste
        - à puces

        1. Une liste
        2. numérotée

        Voici un bloc de code non exécutable :

        ```python
        def salut():
            print("Bonjour!")
        ```

        :::

        ---

        ### Écrire du code

        1. Cliquer sur une cellule existante, ou en ajouter une nouvelle.
        2. Laisser le type de cellule sur **Code**.
        3. Taper du code Python comme dans un fichier `.py`.
        4. Appuyer sur `Shift` ⏎ pour exécuter la cellule.
        5. Observer le résultat qui s'affiche directement sous la cellule.

        #### Exemple :

        ````python
        x = 2 + 2
        print(f'Le résultat est {x}')
        ````

        #### Résultat affiché :

        ```
        Le résultat est 4
        ```

        ---

        ### Exécuter du code

        1. Cliquer dans la cellule contenant du code Python.
        2. Appuyer sur `Shift` ⏎ (ou cliquer sur le bouton ▶ dans la barre d'outils).
        3. Pour exécuter toutes les cellules du notebook d'un coup, cliquer sur le bouton ▶▶ dans la barre d'outils.

        #### Exemple :

        ````python
        ## Définir une fonction
        def bonjour(nom):
            print(f'Bonjour, {nom}!')

        ## Appeler la fonction
        bonjour('Marie')
        ````

        #### Résultat affiché :

        ```
        Bonjour, Marie!
        ```

        ---

        ## Astuces

        - Tu peux déplacer une cellule vers le haut ou le bas à l'aide des flèches ↑ ↓ dans la barre d'outils.
        - Pour insérer une cellule au-dessus ou au-dessous, utiliser les boutons **＋** ou **Insert Cell Below/Above**.
        - Les fichiers `.ipynb` peuvent être ouverts dans d'autres outils comme **JupyterLab** ou **VS Code**.
        - Les cellules Markdown peuvent contenir des titres, des listes, des images, des liens, et même des équations
        mathématiques en format TeX :

        ### Écrire des équations mathématiques (TeX)

        1. Cliquer sur une cellule existante ou en créer une nouvelle.
        2. Changer son type en **Markdown**.
        3. Insérer l'équation LaTeX entre `$$ ... $$` pour une formule centrée,
           ou entre `$ ... $` pour une formule en ligne.
        4. Appuyer sur `Shift` ⏎ pour afficher le rendu.

        #### Exemple (formule centrée) :

        ````markdown
        La formule quadratique est :

        $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$
        ````

        #### Exemple (formule en ligne) :

        ````markdown
        La solution est donnée par $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.
        ````

        #### Résultat affiché :

        :::tip .

        La formule quadratique est :

        $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

        La solution est donnée par $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.

        :::

    <TabItem value="creer-projet" label="🗂️ Créer un projet PyCharm">

        :::note Pourquoi cette recette n'est plus utilisée dans le cours?
        Dans le cours, vous n'avez **pas à créer de projet vous-même** : vos dépôts (exercices, TP) sont créés pour vous lorsque vous [acceptez un dépôt Classroom 50](/recettes/accepter-depot-classroom50). Il suffit ensuite de les cloner dans PyCharm.

        Cette recette demeure utile pour un projet personnel, ou si vous installez PyCharm sur votre ordinateur et voulez faire un premier essai.
        :::

        ---

        Un **projet PyCharm** est un dossier contenant tous les fichiers liés à un programme Python.
        Il contient habituellement :

        - des fichiers `.py` (code Python)
        - un environnement virtuel (`venv`) pour gérer les dépendances
        - d'autres fichiers comme des notebooks Jupyter, des images, ou des fichiers Markdown

        ---

        ## Étapes pour créer un projet

        1. Ouvrir **PyCharm**.
        2. Sur l’écran d’accueil, cliquer sur **New Project** (ou **File > New Project**
        si un autre projet est déjà ouvert).
        3. Choisir un **emplacement** pour le projet, idéalement dans votre [répertoire GitHub](/recettes/autres-recettes?onglet=creer-repertoire-github)
        (par exemple : `Desktop/mon_repo/nom_du_nouveau_projet`).
        4. Choisir un **environnement Python** :
           - Cocher *Create a welcome script* pour qu'un fichier `main.py` soit créé automatiquement.
           - Laisser l’option *Project venv* cochée pour créer un environnement isolé.
           - Vérifier que l’interpréteur sélectionné est bien une version de **Python 3.x**.
        5. Cliquer sur **Create**.
        6. Si vous avez déjà un projet ouvert, cliquer sur **New Window**
        pour ouvrir le nouveau projet dans un nouvel onglet.

        ---

        ## Comprendre la structure du projet

        Une fois le projet créé, PyCharm affiche :

        - un dossier principal (nom du projet)
        - un dossier `venv/` contenant l’environnement virtuel
        - un fichier `main.py` (optionnel)
        - l’éditeur principal au centre, l’arborescence des fichiers à gauche

        ---

        ## Ajouter un premier fichier

        1. Dans la colonne de gauche, cliquer-droit sur le dossier du projet.
        2. Choisir **New > Python File**.
        3. Donner un nom au fichier (ex : `test`) et appuyer sur ⏎.
        4. Un nouveau fichier `test.py` est créé.

        ---

        ## Astuces

        - Toujours créer un projet avant d’écrire du code, pour bien organiser vos fichiers.
        - Éviter les accents, espaces ou caractères spéciaux dans les noms de dossiers.
        - Le projet peut contenir aussi des notebooks Jupyter, des fichiers Markdown, etc.

        :::note Pourquoi cette recette n'est plus utilisée dans le cours?
        Dans le cours, vos dépôts GitHub sont **créés automatiquement** lorsque vous [acceptez un dépôt Classroom 50](/recettes/accepter-depot-classroom50), et votre enseignant y a déjà accès : inutile de créer un dépôt ou d'inviter un collaborateur.

        ---

        :::info-nt

        1. Allez sur [github.com](https://github.com) et connectez-vous à votre compte
        2. Cliquez sur l'onglet **`Repositories`** en haut de la page
        3. Cliquez sur le bouton vert **`New`** en haut à droite
        4. Dans la section **`General`** :
           - Dans le champ **`Repository name`**, nommez votre dépôt en suivant les directives de votre enseignant.<br/>
             Par exemple, pour votre dépôt de code contenant les exercices du cours, le format attendu est :<br/><br/>`A26-GrXXXX-MATRICULE-PRENOM-NOM` *(ex : A26-Gr1010-123456-John-Doe)* où
             <br/>`XXXX` est votre numéro de groupe,
             <br/>`MATRICULE` votre matricule étudiant,
             <br/>`PRENOM` et `NOM` vos prénom et nom de famille.


           - Le champ **`Description`** est optionnel, mais il est recommandé d'y décrire au minimum le rôle du dépôt. <br/>Par exemple : *"Exercices réalisés dans le cadre du cours 420-SN1"*.<br/><br/>
        5. Dans la section **`Configuration`** :
           - **`Choose visibility`** : sélectionnez **`Private`** \
                Votre dépôt ne sera visible que par vous et les collaborateurs que vous invitez.
           - **`Add README`** : activez le bouton pour le mettre à **`ON`** \
                Le contenu de ce fichier s'affiche sur la page d'accueil de votre dépôt et sert de carte de visite pour votre projet. \
                GitHub créera automatiquement un fichier `README.md` en reprenant la description que vous avez saisie plus haut.


           - **`Add .gitignore`** : sélectionnez **`Python`** \
                Cela exclut automatiquement les fichiers inutiles de votre dépôt de code.
           - **`Add license`** : laissez à **`No license`**
        6. Cliquez sur **`Create repository`**

        :::

    <TabItem value="git-avec-github-desktop" label="🐙 Git avec GitHub Desktop">

        :::note Pourquoi cette recette n'est plus utilisée dans le cours?
        Dans le cours, on clone, on fait des *commit-push* et on récupère les modifications **directement dans PyCharm** : suivez plutôt la recette [🐙 Git avec PyCharm](/recettes/enclasse_pycharm).

        Cette façon de faire reste utile si vous travaillez un jour avec un autre éditeur que PyCharm (par exemple *VS Code*), ou si vous préférez une application dédiée pour gérer vos dépôts GitHub.
        :::

        ---

        Voici la procédure à suivre lorsque vous vous connectez à un poste au cégep, en utilisant ***GitHub Desktop*** :

        :::tip-nt Prérequis
        👉 *GitHub Desktop* doit être installé sur l'ordinateur. Sinon, suivez d'abord la recette [💻 Installer GitHub Desktop](/recettes/autres-recettes?onglet=installer-github-desktop).
        :::

        :::info-nt

        ## 1️⃣ Cloner un répertoire GitHub

        1. Ouvrez *GitHub Desktop*
        2. Allez dans le menu `File` > `Clone repository...`
        3. Cliquez sur `Sign in` et connectez-vous avec votre compte GitHub
        4. Une fois connecté, sous l'onglet `GitHub.com`, vous verrez la liste de vos répertoire
            1. Sélectionnez le répertoire que vous voulez cloner (par exemple, `Cours_420-SN1`)
            2. Cliquez sur `Choose...` pour choisir l'emplacement local où cloner le répertoire
                - 👉 Naviguez et choisissez le `Bureau`
            3. Cliquez sur `Clone`
        5. Votre répertoire est maintenant cloné (copié) localement sur le bureau de votre poste de travail
        6. Gardez *GitHub Desktop* ouvert pour la suite des opérations.

        :::

        :::note-nt

        ## 2️⃣ Ouvrir un projet dans PyCharm

        1. Ouvrez *PyCharm*
        2. Cliquez sur le bouton `Open` (ou allez dans le menu `File` > `Open...`)
        3. Naviguez jusqu'au dossier de votre répertoire cloné (normalement sur le `Bureau`)
        4. Dans votre répertoire, sélectionnez le dossier du projet que vous voulez ouvrir (par exemple, `Exemples_exercices`)
            - 👉 Ne sélectionnez pas le *repo* entier, mais le dossier spécifique du projet à l'intérieur du *repo*
            - Si vous n'avez pas encore créé de projet dans le répertoire, vous pouvez créer un nouveau dossier pour votre nouveau projet (cliquez sur `Nouveau dossier` en haut à gauche)
        5. Une fois le dossier du projet sélectionné (en bleu), cliquez sur `Select Folder`
            - Cliquez sur `Trust Project` si PyCharm vous le demande
            - 👉 PyCharm va ouvrir le projet et indexer les fichiers (cela peut prendre quelques instants)
        6. Vous pouvez maintenant éditer et exécuter les fichiers Python de votre projet dans PyCharm.

        :::

        :::tip-nt

        ## 3️⃣ Faire des commit-push

        Même si PyCharm sauvegarde localement les modifications que vous faites dans vos fichiers, elles ne sont pas sauvegardées dans votre compte GitHub. Si une panne d'électricité survenait, vous perdriez toutes vos modifications non poussées sur GitHub. Il est donc important de **faire des commit-push régulièrement**, par exemple après chaque exercice complété :

        1. Allez sur *GitHub Desktop*.
        2. Vous verrez les fichiers modifiés dans l'onglet `Changes`
            - Si vous cliquez sur un fichier, vous verrez les modifications apportées à ce fichier
        3. Dans le champ `Summary`, ajoutez un message de commit décrivant vos modifications (par exemple, `Exercice 1 complété`)
        4. Pour envoyer vos modifications sur GitHub, cliquez sur les boutons bleus :
            1. `Commit to main`
            2. `Push origin`
        - 👉 N'oubliez pas de faire `Push` après chaque `Commit`. Tant que vous ne faites pas `Push`, vos modifications ne sont pas sauvegardées sur GitHub.
        :::

        ::::warning-nt
        ## 🧑‍💻 Ordinateur personnel
        Si vous travaillez sur votre ordinateur personnel :
        - Assurez-vous d'avoir installé [GitHub Desktop](/recettes/autres-recettes?onglet=installer-github-desktop) et [PyCharm](/recettes/installer-pyCharm)
        - Clonez votre répertoire GitHub sur votre ordinateur personnel en suivant la même procédure que ci-dessus
            - 👉 Mais vous n'avez pas besoin de le cloner à chaque fois, seulement la première fois
        - Ouvrez le projet dans PyCharm comme décrit ci-dessus
        - N'oubliez pas de faire des commit-push régulièrement pour sauvegarder vos modifications sur Git

        :::danger TRÈS IMPORTANT
        Si vous travaillez sur plusieurs ordinateurs (par exemple, votre ordinateur personnel et un poste au cégep), vous devez toujours **synchroniser** vos modifications entre les deux ordinateurs pour éviter des conflits.

        Chaque fois que vous revenez travailler sur votre ordinateur personnel, vous devez **récupérer les modifications** que vous avez faites sur un autre ordinateur (par exemple, au cégep) avant de continuer à travailler sur vos fichiers.

        Pour cela, dans *GitHub Desktop*, cliquez sur les boutons bleus :
        1. `Fetch origin`
        2. `Pull origin`

        C'est l'équivalent de `Commit-Push` mais dans l'autre sens : vous récupérez les modifications que vous avez faites sur un autre ordinateur.
        - 👉 Si vous ne faites pas cela avant de continuer à travailler sur vos fichiers sur votre ordinateur personnel, vous risquez d'avoir des conflits lorsque vous essayerez de faire un `Commit-Push`.

        :::
        ::::
