# 🚀 Installer PyCharm

:::danger-nt
*PyCharm* est déjà installé sur les ordinateurs du cégep.\
Cette procédure est seulement pour installer *PyCharm* sur votre ordinateur personnel.
:::

*PyCharm* est le logiciel qui va nous servir pour coder en Python. \
Il est gratuit et est l'un des logiciels de référence dans l'industrie pour le langage Python.

Pour installer PyCharm à la maison :

:::warning Utilisateurs de Mac
Si vous utilisez un Mac, vous devez installer **Git**. \
*Il n'est pas nécessaire d'installer Xcode.*

1. Ouvrez l'application **Terminal** sur votre Mac.
2. Copiez et exécutez la commande suivante :
   ```bash
   xcode-select --install
   ```
3. Une fenêtre s'ouvre. Cliquez sur **Installer** et attendez la fin de l'installation.
4. Vérifiez que Git est bien installé avec la commande :
   ```bash
   git --version
   ```

Si un numéro de version s'affiche, Git est installé et pourra être utilisé directement dans PyCharm.
:::

1. Aller sur le site de [PyCharm](https://www.jetbrains.com/pycharm/download/).
2. Trouver la version *PyCharm Unified Product*.
3. Cliquer sur le lien de téléchargement (*Download*).
4. Double-cliquer sur le fichier "pycharm-2026.2.1.exe" dans vos téléchargements.
5. Suivre les instructions d'installation et cocher les options suivants :
    - *Create Desktop Shortcut / PyCharm*, afin de créer un raccourci de l'application sur votre bureau.
    - *Create Associations / .py*, afin d'associer le double-clic sur un fichier Python à l'application PyCharm.

## Tester l'installation de PyCharm

1. Lancer PyCharm.
2. [Créer un nouveau projet.](/recettes/autres-recettes?onglet=creer-projet)
3. Créer un nouveau fichier Python.
4. Écrire un petit programme et le rouler, par exemple :

```python
print("Hello world")
```

5. Exécuter le programme.

Vous devriez voir dans le bas de PyCharm sur fond noir, le message "Hello world" apparaitre. \
Si c'est bien le cas, votre installation est fonctionnelle.

## Configurer PyCharm pour le cours

Ces réglages sont **déjà faits sur les ordinateurs du cégep**. Faites-les aussi sur votre ordinateur personnel afin de travailler dans les mêmes conditions qu'en classe (et qu'aux examens).

Tous les réglages se trouvent dans la fenêtre des paramètres :
- **Windows** : menu **File > Settings…** (ou <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>S</kbd>)
- **Mac** : menu **PyCharm > Settings…** (ou <kbd>⌘</kbd> + <kbd>,</kbd>)

:::tip
Le champ de recherche en haut à gauche de la fenêtre des paramètres permet de trouver rapidement une option : tapez un mot-clé (par exemple `Inline` ou `Hints`).
:::

### 1️⃣ Désactiver l'autocomplétion

PyCharm peut deviner et écrire des lignes de code complètes à votre place. C'est pratique pour un programmeur d'expérience, mais pour apprendre à programmer, c'est **vous** qui devez écrire le code!

1. Ouvrir les paramètres.
2. Aller dans **Editor > General > Code Completion > Inline**.
3. Décocher **Enable inline completion using language models**.
4. Cliquer sur **OK**.

### 2️⃣ Désactiver certains *Inlay Hints*

Les *Inlay Hints* sont de petites annotations grises que PyCharm ajoute directement dans votre code. Elles **ne font pas partie du code**, mais elles ressemblent à du code et peuvent porter à confusion : on croit qu'il faut les écrire, ou on ne comprend plus ce qu'on a réellement tapé.

1. Ouvrir les paramètres.
2. Aller dans **Editor > Inlay Hints**.
3. Déplier **Types > Python > Python type hints**.
4. Décocher **Function return types**.
5. Décocher **Parameter type annotations**.
6. Cliquer sur **OK**.
